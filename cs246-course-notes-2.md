## Description

Covers data mining and machine learning algorithms for analyzing very large datasets, emphasizing MapReduce and Spark for parallel processing.

**Topics:**
- Frequent itemsets & association rules
- Near-neighbor search / Locality-Sensitive Hashing (LSH)
- Dimensionality reduction
- Recommendation systems
- Clustering
- Link analysis (PageRank)
- Large-scale supervised machine learning
- Data streams
- Web mining / computational advertising
- Graph neural networks & embeddings

## Reference text

*Mining of Massive Datasets* by Leskovec, Rajaraman, and Ullman — free download available at [mmds.org](http://www.mmds.org/)

## Prerequisites

- Basic CS principles / non-trivial programming ability (CS107 or CS145 or equivalent)
- Java and Python (most assignments use Spark)
- Basic probability theory (CS109 or Stat116 or equivalent, helpful not required)
- Rigorous proof-writing (CS103 level)
- Basic linear algebra (Math 51, Math 103, Math 113, CS205, or EE263)
- Algorithmic analysis (CS161 level)
